# Code smell examples

## Background

You are a teacher in typescript and have a class of students that have been using typescript for 6 months. They have build application using vite and vanilla typescript to create dom elements, handle events and make some custom logic.

## Your assignment

I want you to create a number of tasks for code smells including DRY, magic numbers and refactoring large functions into smaller ones. A couple of functions where we can work on using objects as arguments instead of many arguments and a couple of examples where nested if/else statements can be rewritten in a more readable way.

## Results

I want the result to be code that we can use in class and discuss to make better. Please also provide the expected results after the code smell or refactoring is done. Give us the code smell and the excepted result right after, before the next code smell. This makes it easier to train and analyse our response.

### Important

- The code must be using typescript.
- If the code is hard to understand, provide comments to help the students understand the code.
- Use descriptive variable and function names.
